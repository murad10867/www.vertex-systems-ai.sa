# Vertex Systems AI Mobile

هذا مجلد التطبيق الأصلي (Native App) المبني بـ Capacitor.

## الهوية
- App Name: Vertex Systems AI
- App ID: com.vertexsystems.ai
- Web source: https://murad10867.github.io/www.vertex-systems-ai.sa/

## Android
```bash
cd mobile-app
npm install
npx cap add android
npx cap sync android
npx cap open android
```

## iOS
```bash
cd mobile-app
npm install
npx cap add ios
npx cap sync ios
npx cap open ios
```

> بناء نسخة iPhone النهائية يحتاج Xcode وحساب Apple Developer للتوقيع أو TestFlight.
